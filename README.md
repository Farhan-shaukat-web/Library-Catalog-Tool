# 📚 Library Catalog Tool

A simple and responsive **Library Catalog Tool** developed using **HTML, CSS, and JavaScript**. This application allows users to add, search, and delete book records through an easy-to-use and modern interface.

---

## 🌟 Features

- Add new books
- Search books by title, author, category, or book ID
- Delete book records
- Total books counter
- Duplicate Book ID validation
- Responsive and user-friendly UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in **Visual Studio Code**.
3. Open **index.html** using **Live Server** or any modern web browser.
4. Enter the book details.
5. Click **Add Book** to save the record.
6. Use the search box to find books instantly.
7. Click the **Delete** button to remove a book from the catalog.
